## Sobre mí

Estudiante en la **Universidad Americana (UAM)**, Nicaragua. Construyo aplicaciones móviles nativas, APIs y sitios web.

- **Móvil** — iOS con Swift y Android con Kotlin + Jetpack Compose
- **Backend** — APIs REST con Java y Spring Boot sobre PostgreSQL
- **Web** — React, TypeScript y Tailwind desplegados en Cloudflare Workers
- **Trading algorítmico** — Expert Advisors para MetaTrader 5 en MQL5
